# CNN-Transformer internal-solitary-wave detector

A per-20×20-pixel-block **binary classifier** for internal solitary waves (ISWs)
in SWOT L3 data — not a box detector. `BlocksTokenModel` reads the raw NetCDF
directly, tokenizes the swath into 20×20 blocks, and predicts one ISW-present
probability per block; an optional second-stage **dense refinement head** turns
each block score into a per-pixel map without any pixel labels. This directory
also holds the global-scale inference and map-plotting scripts used for the
figures in the root README. Ten channel-selection variants are trained at three
seeds each (30 models) and scored with the shared `eval/evaluate_block_metrics.py`.

## How the code fits together

```
preprocessing/  →  dataio/  →  models/  →  training/  →  inference/  →  evaluation/  +  eval/evaluate_block_metrics.py  →  aggregate_eval_metrics.py
 derive channels   load & batch  BlocksTokenModel   fit        run over passes    score & aggregate
 + block labels    NetCDF items                                write slim NetCDF
```

### `src/models/` — the `BlocksTokenModel` architecture

The forward pass is **CNN stem → block tokenizer → 2-D positional encoding →
transformer encoder → per-block head**, plus the optional dense head — exactly the
six stages drawn in `figures/cnn_transformer_dense_head_architecture.png`.

| file | role |
|---|---|
| `model_config.py` | `ModelConfig` dataclass — the single source of truth for architecture (channels, `block_size`, `embed_dim`, `depth`, heads, `mlp_ratio`, dropout, spatial-reduction attention, positional-encoding kind, and the dense-head group). Real values live in each run's `args.json` / embedded checkpoint config; the dataclass defaults are stale. |
| `cnn_stem.py` | `CNNStem` — 3× (Conv3×3 no-bias → BatchNorm2d → GELU), stride 1 so full H×W is kept. Maps `[B, C_in, H, W] → [B, D, H, W]`. Its output feeds both the tokenizer and the dense head's skip connection. |
| `block_tokenizer.py` | `BlockTokenizer` — a single `nn.AvgPool2d(block_size, block_size)` pooling stem features into one token per block: `[B, D, H, W] → [B, N, D]` with `N = Bh·Bw`, plus a token mask and `Bh, Bw`. This average-pool is what the dense head later tries to undo at pixel resolution. |
| `posenc.py` | `Learned2DPosEnc` (a tiny 2-conv net) and `build_sincos_2d` (parameter-free 2-D sine/cosine table). The 30 trained models use `sincos2d`. Added to the tokens before the encoder. |
| `transformer.py` | `EncoderBlock` — pre-LN block (LayerNorm → `nn.MultiheadAttention` → residual → LayerNorm → MLP → residual); with `sra=True` it mean-pools keys/values over length-`sra_ratio` windows (spatial-reduction attention) to cut cost on large block grids. `TransformerEncoder` stacks `depth` of them. |
| `head.py` | `TokenHead` — LayerNorm → Linear(D→D/2) → GELU → Linear(D/2→1) → `[B, N]` logits; sigmoid applied in `BlocksTokenModel.forward`. This is the block classifier every detection number comes from. |
| `dense_head.py` | `DenseRefinementHead` — stage 6. Broadcasts each contextual token over its own `block_size²` footprint (`bilinear` default), concatenates full-resolution stem features `F`, then Conv3×3 → GELU → Conv3×3 → GELU → Conv1×1 → `[B, 1, Ht, Wt]` dense logits. Within-block detail comes entirely from `F`; the head never mixes context across block seams. |
| `token_model.py` | `BlocksTokenModel` — assembles all of the above from a `ModelConfig`. `forward(images, block_mask=None, return_heatmap=False, return_dense=False)`; plus `backbone_modules()`, `freeze_backbone()`, `set_train_mode()` for the two-stage dense training (freeze detector, keep its BatchNorm in eval, train only the dense head). |

The diagram is regenerated by `figures/cnn-transformer-diagram.py` (repo root),
which reads a `ModelConfig` so every label tracks the code.

### `src/preprocessing/`

| file | role |
|---|---|
| `preprocess_cycles.py` | Self-contained headless batch driver. Defines `CONFIG` (all filter parameters) and the NaN-aware Gaussian / rolling-mean / stepped-convolution / FFT high-pass + Sobel gradient-magnitude filters and quality masking, then loops over `--cycles` folders under `--data-root`: computes the six derived channels per `.nc`, crops `num_lines`/`num_pixels` to a multiple of 10, and atomically writes back in place. |

### `src/dataio/`

| file | role |
|---|---|
| `dataset.py` | `make_nc_block_dataset(...)` builds in-memory items from NetCDF (auto-split by ratio/seed, or explicit train/valid/test dirs): reads the requested channels + mask, computes majority-vote block labels, floor-crops ragged edges, NaN→0. Each item is `{image [C,Hc,Wc], labels [Bh,Bw], valid [Bh,Bw], id, block_size, grid_shape}`. `load_nc_item()` is the single-file wrapper. |
| `collator.py` | `DataCollatorBlocks` — pads a list of items into a batch (`[B, C, H_max, W_max]`, labels/valid padded, `block_attn_mask` marking real vs. pad tiles for loss and attention). |
| `loader.py` | DataLoader factories: `BlockItemDataset`, `GridShapeBucketBatchSampler` (batches by identical `(Bh, Bw)` to minimize padding), `create_dataloader` / `create_dataloaders_train_val`. |
| `augment.py` | `RandomFlip` — independent H/V flips of image/labels/valid; training split only. |

### `src/training/`

| file | role |
|---|---|
| `train_tokens.py` | Main CLI for the 30 block-classifier models (`python -m src.training.train_tokens`). Builds splits → collator → bucketed loaders → `ModelConfig`/`BlocksTokenModel` → AdamW + cosine, then the `Trainer` loop; writes `args.json`, `checkpoint_epoch_*.pt`, and `best.pt` (best by PR-AUC, with embedded config). |
| `train_dense.py` | Stage-1 (and `--unfreeze_backbone` stage-2) CLI for the dense head: loads a trained detector, freezes the backbone (or keeps a frozen distillation teacher), runs `DenseTrainer`, selects `best.pt` by dense PR-AUC. |
| `train_dense_2.0.py` | Larger self-contained CLI (run the file directly — the `2.0` deliberately blocks `-m`). Trains the dense head then runs the full evaluation into one output tree: asserts the detector is reproduced bit-for-bit, selects a reporting threshold on validation, scores the learned map vs. nearest/bilinear/bicubic/gaussian baselines, computes structural metrics and a pass-level bootstrap CI, draws figures, and with `--run-ablations` sweeps five head variants × seeds. |
| `engine.py` | `Trainer` (block classifier: weighted BCE on valid tokens, grad-clip, checkpoint with embedded `ModelConfig`) and `DenseTrainer` (dense head: freezes backbone, `DenseRefinementLoss`, aggregates the dense map back to blocks for teacher distillation + edge terms). |
| `losses.py` | `build_weighted_bce(alpha)` (`pos_weight = alpha/(1-alpha)`), `FocalLoss` (available, not default), and the dense pieces: `aggregate_dense_to_patch`, `soft_majority_logit`, `edge_aware_smoothness`, `DenseRefinementLoss` (`L = L_patch + λ_teacher·L_teacher + λ_edge·L_edge`). |
| `metrics.py` | `compute_metrics(labels_v, probs_v, threshold)` — sklearn-based binary metrics on valid blocks (accuracy, P/R/specificity, F1, F0.5, IoU, balanced accuracy, ROC-AUC, PR-AUC). Shared by `engine.py`, `dense_eval.py`, `train_dense_2.0.py`. |
| `optim.py` | `build_optim_and_sched` — AdamW + `CosineAnnealingLR`. |
| `eval_tokens.py` | `evaluate_checkpoint(...)` — rebuild a model from a checkpoint and print `Trainer.evaluate` metrics (somewhat stale call signatures). |
| `infer_tokens.py` | `save_heatmap(...)` — quick visual-debug utility: run `return_heatmap=True` and save input-vs-confidence PNGs. |

### `src/inference/`

| file | role |
|---|---|
| `inference.py` | The core inference **library** — no disk writes. `load_model` rebuilds `BlocksTokenModel` from a checkpoint; `infer_model_config_from_checkpoint` recovers what it can from tensor shapes; `inference(...)` returns the `[Bh, Bw]` block probability grid; `dense_inference(...)` returns the per-pixel map. |
| `infer.py` | Batch driver over a standard split, whole-swath. Parses `cnntrans_<variant>_<seed>` → channel vars, runs `inference()` per `.nc`, broadcasts the block grid back to pixels, and writes a slim NetCDF via `common.write_slim_netcdf`. No YOLO-style `.txt` — this model classifies blocks, not boxes. |
| `infer_tiled.py` | Like `infer.py` but splits each ~9860-row global swath into `--tile-height` along-track tiles, runs per tile, and stacks the tile grids — the full-attention + sincos2d model is sensitive to along-track grid height, so whole swaths otherwise come out almost all-negative. `--dense` stitches per-pixel maps instead. |
| `common.py` | `write_slim_netcdf(...)` — the shared output writer: lat/lon + `block_mask`, `iw_bbox_mask`, `gaussian_filter_highpass`, `quality_flag`, plus this run's `internal_wave_bbox_mask` / `internal_wave_bbox_confidence`, zlib-compressed. Variable names match `eval/evaluate_block_metrics.py`'s defaults. |
| `plot_detection_frequency.py` | Global map: per 20×20 block, the count of repeat cycles whose block-mean confidence cleared a per-\|lat\|-band cutoff (detection recurrence). Also prints named-region shares. |
| `plot_highpass_variance.py` | Global map: per 20×20 block, the mean-over-cycles variance of high-pass SSHA over confidence-gated pixels — a proxy for detected-wave surface amplitude. |
| `plot_global_confidence_map.py` | Global map of per-cell mean `internal_wave_bbox_confidence` (`pcolormesh`), or `--scatter` per-pixel mode for dense-head outputs. |
| `plot_pass_section.py` | Qualitative per-pass figure: the swath section inside a lat/lon `--box`, high-pass SSHA base with a translucent `confidence > threshold` overlay, in array or true Cartopy coords. |
| `plot_region_month_polar.py` | Per-region polar/radar plot: calendar month vs. monthly cleared-block count and monthly high-pass-SSHA variance — a seasonal-cycle-by-region figure. |

### `src/evaluation/`

| file | role |
|---|---|
| `eval.py` | Block-level evaluation directly from a built `test_loader`, self-contained AUROC/AUPRC (no sklearn). `evaluate_test_loader(...)` loads the model, accumulates overall + per-sample metrics, optionally writes `metrics.json` / `sample_metrics.csv` / viz PNGs. The in-memory counterpart to `eval/evaluate_block_metrics.py`. |
| `dense_eval.py` | Evaluation for dense maps without pixel ground truth: builds nearest/bilinear/bicubic/gaussian baselines from the same block probs, scores detection fidelity after re-aggregation, and computes structural metrics (grid-artifact ratio, image-structure alignment, flip equivariance, localized-perturbation response). `select_best_threshold` sweeps on validation; `evaluate_dense_loader` is the driver. |
| `viz.py` | Matplotlib helpers: confusion matrix, metric bars, probability histograms, AUC curves, per-sample panels, and `plot_dense_comparison` (dense map vs. interpolation baselines). |

### `src/labeling/`

`qt_labeler.py` — standalone PySide6 app to drag a 20×20 grid over a chosen
variable and save `block_mask`, draw freeform boxes and save a rasterized
`iw_bbox_mask`, or edit existing labels. Produces the ground-truth NetCDF
variables that `dataio/dataset.py` reads.

### Top-level orchestration

| file | role |
|---|---|
| `eval_run_all.py` | Runs `eval/evaluate_block_metrics.py` once per model under `results/` (needs both `test/netcdf` and `valid/netcdf`), scoring each model's test output against its own valid output. `--majority-threshold` fixed at `0.25`. |
| `aggregate_eval_metrics.py` | Reads the 30 `block_metrics_overall.csv` files, parses `cnntrans_<variant>_<seed>`, rolls the three seeds per variant into mean / sample-std → `eval_results/summary_by_variant.csv`. |
| `run_ood_block_eval.py` | Runs the same inference → eval → aggregate pipeline on the labeled OOD datasets in `/workspace/OOD/`, symlinking each run's in-distribution `valid` outputs so the confidence threshold is still selected in-distribution. Defaults to variants `gfh` + `shg`. |
| `batch_run_inference/gen_inference_assignments.py` | Static job partitioner: lists every `runs/<run>` with a `best.pt`, forms `(run, split)` jobs, round-robins them across GPU devices, writes `device{N}.txt` for a shared-nothing parallel launch. |

## The 10 channel-selection variants

Variants differ only in which NetCDF variable(s) are stacked as input channels;
ground truth is always each file's `block_mask` at `block=20`.

| variant | channels | `in_channels` |
|---|---|---|
| `sqm` | `ssha_quality_masked` | 1 |
| `sch` | `stepped_convolution_highpass` | 1 |
| `gm` | `gradient_magnitude` | 1 |
| `gfh` | `gaussian_filter_highpass` | 1 |
| `rmh` | `rolling_mean_highpass` | 1 |
| `fft` | `fft_highpass` | 1 |
| `shg` | `ssha_quality_masked`, `rolling_mean_highpass`, `gradient_magnitude` | 3 |
| `s0g` | `ssha_quality_masked`, `gradient_magnitude` | 2 |
| `sh0` | `ssha_quality_masked`, `rolling_mean_highpass` | 2 |
| `0hg` | `rolling_mean_highpass`, `gradient_magnitude` | 2 |

## Running it

Needs `torch`, `xarray`, `netCDF4`, `scikit-learn`, `pandas`, `numpy`. Run from
`cnn-transformer/`. One `(variant, seed)`, using `gfh` as the example:

```bash
# train
python3 -m src.training.train_tokens \
    --train_dir /workspace/data/bob/netcdf/train \
    --valid_dir /workspace/data/bob/netcdf/valid \
    --test_dir  /workspace/data/bob/netcdf/test \
    --mask_var block_mask --block 20 \
    --channel_vars gaussian_filter_highpass --in_channels 1 \
    --seed 123 --epochs 100 --lr 5e-5 --wd 0.05 --alpha 0.6 \
    --embed_dim 128 --depth 64 --heads 8 --mlp_ratio 3.0 \
    --posenc sincos2d --sra --sra_ratio 2 \
    --save_dir runs/cnntrans_gfh_123

# NetCDF inference (writes results/cnntrans_gfh_123/<split>/netcdf/)
python src/inference/infer.py --run-name cnntrans_gfh_123 --split test  --device 0
python src/inference/infer.py --run-name cnntrans_gfh_123 --split valid --device 0

# block-level eval + aggregate the 3 seeds per variant
python eval_run_all.py
python aggregate_eval_metrics.py
```

Train the dense head with `python src/training/train_dense_2.0.py --help`. For the
full 30-run sweep use `batch_run_inference/gen_inference_assignments.py` +
worker scripts; for OOD use `python run_ood_block_eval.py`.

|---|---|

| `results/cnntrans_<variant>_<seed>/<split>/netcdf/*.nc` | slim NetCDFs with `internal_wave_bbox_mask` / `internal_wave_bbox_confidence` added |
| `eval_results/cnntrans_<variant>_<seed>/block_metrics_{overall,per_file}.csv` + `summary_by_variant.csv` | block-level metrics, per run and aggregated by variant |
